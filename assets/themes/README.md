# Bundled themes

The UI palettes in `bundled.json` are adapted from the theme collection shipped by
[`gpui-component`](https://github.com/longbridge/gpui-component/tree/main/themes).

- Ayu: Zed Industries
- Catppuccin: Catppuccin contributors
- Gruvbox: Pavel Pertsev
- Tokyo Night: Folke Lemaitre
- Solarized: Ethan Schoonover

Only the application UI tokens used by Ruiz are bundled. The original projects remain the
authoritative sources for their full editor and syntax-highlighting palettes.
